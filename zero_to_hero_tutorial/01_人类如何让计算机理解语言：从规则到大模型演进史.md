# 第 1 篇：计算机如何读懂语言？从人工规则到大模型演进史

> **阅读前须知**：本篇不需要任何高等数学或编程背景。我们将从人类对计算机的最初探索讲起，带你一步步理解大模型（LLM）究竟是在什么背景下被发明出来的，以及它究竟解决了前人什么无法逾越的难题。

---

## 💻 一、计算机的天然缺陷：它只懂数字，不懂人类语言

首先请思考一个最本质的事实：
**计算机的硬件核心（CPU 和 GPU），本质上只是无数由晶体管组成的微型电路，它唯一擅长的事情，就是极速计算浮点数的「加法」和「乘法」。**

计算机根本不知道什么是“猫”，什么是“开心”，什么是“我爱你”。
对于计算机而言，屏幕上的汉字或英文字符，只是一串无意义的二进制编码（比如 UTF-8 编码中，“大”这个字的十六进制代码是 `0xE5 0xA4 0xA7`）。

人类要想让计算机能对话、能写诗、能编程，就必须完成一个根本性的跨越：
**如何把人类丰富、带有歧义、充满上下文语境的自然语言，转化为数字？并让计算机通过纯粹的数学计算，“理解”语言并生成语言？**

为了解决这个问题，人类科学家经历了整整四代探索。

---

## 📜 二、第一代：基于人工规则与专家系统（1950s - 1980s）

在计算机科学诞生初期，科学家们认为人类语言是有严格语法规则的。

### 核心做法：
语言学家人工编写成千上万条逻辑规则：
- `句子 = 主语 + 谓语 + 宾语`
- 如果主语是“我”，谓语可以是“吃”，宾语可以是“苹果”。
- 遇到英语单词 `"bank"`，如果前文有 `"river"`，就翻译为“河岸”；如果有 `"money"`，就翻译为“银行”。

### 为什么彻底失败？
1. **语言规则无穷无尽**：自然语言充斥着成语、倒装句、隐喻、俚语和错别字，规则写得越多，规则之间就越互相冲突。
2. **缺乏泛化能力**：人类只要说一句规则库里没有的表达（例如：“今天我被老板炒了鱿鱼”），系统就会瞬间崩溃。

事实证明：**靠人类肉眼穷举语言规则是死路一条。**

---

## 📊 三、第二代：统计语言模型与 N-gram（1990s - 2000s）

既然人工写规则走不通，统计学家们提出了全新思路：**不要人工写规则，让计算机去统计真实人类书写的大量文章！**

### 1. 什么是“语言模型（Language Model）”？
数学家对语言模型的定义极其质朴：
> **语言模型，就是一个计算“一句话在现实世界中出现的概率”的数学函数。**

例如，对于两句话：
- $S_1$ = “今天天气真好”
- $S_2$ = “好真天气今天”

一个好的语言模型应该计算出：$P(S_1) = 0.05$（很常见），而 $P(S_2) = 0.0000001$（人类几乎不这么说）。

根据概率论的**链式法则（Chain Rule）**，一句话出现的联合概率，等于逐个词出现的条件概率相乘：
$$ P(w_1, w_2, w_3, \dots, w_n) = P(w_1) \times P(w_2 \mid w_1) \times P(w_3 \mid w_1, w_2) \dots \times P(w_n \mid w_1, \dots, w_{n-1}) $$

这个公式看似完美，但计算机在实际计算时崩溃了：
当句子长达 20 个字时，条件概率 $P(w_{20} \mid w_1, \dots, w_{19})$ 要求计算机去统计：**在历史上所有文章中，前面 19 个字完全一模一样的情况下，第 20 个字是 $w_{20}$ 的频率**。
现实中，哪怕整个互联网的所有文本加起来，前面 19 个字完全一样的概率也几乎是 **0**！这就是著名的**「数据稀疏与维度灾难」**。

### 2. N-gram 的妥协（马尔可夫假设）
为了能算出来，统计学家做了一个妥协：**假定第 $t$ 个词出现的概率，只与它前面的 $N-1$ 个词有关，跟更早以前的词完全无关！**
- **2-gram（Bi-gram）**：每个词只看前 1 个词：$P(w_t \mid w_1, \dots, w_{t-1}) \approx P(w_t \mid w_{t-1})$
- **3-gram（Tri-gram）**：每个词只看前 2 个词：$P(w_t \mid w_1, \dots, w_{t-1}) \approx P(w_t \mid w_{t-2}, w_{t-1})$

### 致命死穴：
1. **短视，无法理解长文本**：如果你写一篇文章，开头说“小明是个法国人……”，在经过 500 字后问“他最擅长的母语是___”，N-gram 只看前两个词，根本不可能答对。
2. **没有任何概念理解**：在统计模型中，“苹果”和“梨”是两个完全不相关的独立符号。即使模型见过“我吃了一个苹果”，它也无法推断出“我吃了一个梨”是否合理。

## 🧠 四、第三代：分布式词向量与循环神经网络（2010s）

2013 年，Google 提出了里程碑式的 **Word2Vec**，彻底颠覆了符号表示法。

### 1. 核心飞跃：词嵌入向量（Word Embedding）
人类想通了：**不要用离散的孤立代号表示词，而是把每个词表示为高维空间里的一个坐标点（一个向量，比如 512 个数字）！**
- 著名的语言学假设：*“一个词的含义，由它经常与哪些词同时出现所决定（Distributional Hypothesis）。”*
- 如果把词映射到多维空间中，在大量文本训练后，你会惊奇地发现数学几何与人类常识奇迹般地重合了：
  $$ \vec{v}_{\text{国王}} - \vec{v}_{\text{男人}} + \vec{v}_{\text{女人}} \approx \vec{v}_{\text{王后}} $$
  “苹果”和“梨”在空间中的距离会非常近，而“苹果”和“量子力学”距离极远。

---

### 2. 补齐底座：什么是神经网络？它是怎么“学会”知识的？

> 💡 **很多教材直接从词向量跳到 RNN，导致零基础同学一头雾水。到底什么是“神经元”？什么是“隐藏层”？它到底是怎么从数据中学习的？我们用最接地气的生活例子彻底讲明白。**

#### (1) 单个人工神经元：一个带旋钮的打分器
生物学中，人脑神经元通过树突接收多个电信号，在细胞核汇总，超过一定阈值后通过轴突激发传递。
数学家把这个过程抽象成了一个极其简单的数学公式：

```
输入特征 x1 (离地铁距离) ──► [ 权重旋钮 w1 ] ──┐
输入特征 x2 (房子总价)   ──► [ 权重旋钮 w2 ] ──┼──► [ 求和 ∑(w*x) + 偏置 b ] ──► [ 激活函数 f ] ──► 输出 y (买/不买)
输入特征 x3 (是否带学区) ──► [ 权重旋钮 w3 ] ──┘
```

1. **输入（$x_1, x_2, x_3$）**：客观事实数据。
2. **权重（Weights, $w_1, w_2, w_3$）**：**每个因素在决策中占多大分量（重要程度）**。
   - 如果你极度看重学区，学区权重 $w_3$ 就会调得非常大；
   - 如果你不在乎价格，价格权重 $w_2$ 就会接近 0。
3. **偏置（Bias, $b$）**：基础门槛/自身倾向性（比如你天生买房意愿就很强，即使条件一般也想买，$b$ 就是正数）。
4. **加权求和**：
   $$ z = w_1 x_1 + w_2 x_2 + w_3 x_3 + b = \sum_{i=1}^n w_i x_i + b $$

#### (2) 为什么必须有「激活函数（Activation Function）」？
如果神经元只做 $z = \sum w_i x_i + b$ 这种加减乘除，它在数学上叫**线性变换**。
线性变换的致命缺陷是：**无论你把多少个神经元串联在一起，100 层的线性变换在代数上依然完全等价于仅仅只有 1 层！**
$$ W_2(W_1 x + b_1) + b_2 = (W_2 W_1) x + (W_2 b_1 + b_2) = W_{\text{new}} x + b_{\text{new}} $$
这意味着，没有非线性激活，多层神经网络就丧失了深度的意义，根本无法拟合现实世界中千变万化的曲折规律！

**激活函数（如 $\text{ReLU}$、$\text{Sigmoid}$、$\tanh$）**就像是一个“非线性开关”：
- 它将输入进来的线性加权和，通过曲线进行扭曲与折叠；
- 有了激活函数，多层神经网络就能像折纸一样，在多维空间中折叠出极其复杂的曲面，**理论上可以逼近宇宙中任意复杂的数学函数**（通用近似定理 Universal Approximation Theorem）！

#### (3) 什么是多层神经网络与“隐藏层（Hidden Layer）”？
把成百上千个神经元分层排列，前一层的输出作为后一层的输入，就组成了**多层感知机（MLP / 神经网络）**：

```
输入层 (Input Layer)       隐藏层 (Hidden Layers)       输出层 (Output Layer)
[ 词向量维度 1 ] ──────► ( 神经元 h1 ) ──────► ( 神经元 h'1 ) ──────► [ 下一个词打分 ]
[ 词向量维度 2 ] ──────► ( 神经元 h2 ) ──────► ( 神经元 h'2 ) ──────► [ 下一个词打分 ]
[ 词向量维度 3 ] ──────► ( 神经元 h3 ) ──────► ( 神经元 h'3 ) ──────► [ 下一个词打分 ]
```
- **为什么叫“隐藏层”？**
  因为输入是人类给的文字，输出是最终的预测结果，这两头都是看得见摸得着的。而中间这些层，是**计算机内部自主形成的高维抽象概念表征（Representation）**，人类很难直接用一两个词去定义中间神经元到底在想什么，因此被称为“隐藏状态（Hidden State）”。

#### (4) 神经网络是怎么“学习”的？（损失函数与反向传播）
网络搭好了，但一开始里面的权重旋钮（$W$ 和 $b$）全是**随机初始化的乱码**。它怎么学会人类知识的？
这个学习过程完全模拟了人类的“犯错-反省-改正”机制：

```
      【前向传播 Forward】
      输入数据 ──► 神经网络计算 ──► 得到乱猜的预测值
                                           │
                                           ▼
      【损失函数 Loss Function】比较预测值与真实答案的差距
                                           │
                                           ▼
      【反向传播 Backpropagation】利用微积分链式法则，顺藤摸瓜找出每个旋钮对犯错的责任大小 (梯度 Gradient)
                                           │
                                           ▼
      【梯度下降 Gradient Descent】把每个旋钮朝减少犯错的方向微调一点点 (更新参数 W)
```

1. **第一步（前向瞎猜）**：给模型输入“太阳从东边”，模型一顿乱算，吐出下一个字是“西瓜”。
2. **第二步（算差距 Loss）**：损失函数发现标准答案是“升”，预测概率和事实差了十万八千里，给出一个很大的惩罚分数（Loss）。
3. **第三步（反向算责任）**：利用高等数学的**链式求导法则（Chain Rule）**，从后向前计算输出误差对每一个权重参数的偏导数（称为**梯度 Gradient**）。梯度告诉我们：“如果把第 354 号旋钮稍微拧大一点，总误差就会减小！”
4. **第四步（更新旋钮）**：按照梯度的相反方向，微调所有的权重参数（这个过程叫**梯度下降**）。
5. **重复数十亿次**：当把互联网上几万亿个词喂给模型，历经成百上千卡 GPU 几个月的日夜调整，所有的旋钮都达到了极致精密的和谐状态——大模型就此诞生！

---

### 3. 为什么传统神经网络处理文本会崩溃？循环神经网络（RNN）的诞生
搞懂了基础神经网络，我们立刻面临一个致命挑战：
**传统的神经网络，输入大小必须是固定的！**
- 比如设计一个能输入 3 个词的网络，它就只能吃 3 个词；
- 但人类说话有长有短，有的问句只有 2 个字（“在吗？”），有的文章长达 1 万字！
- 怎么让同一个神经网络，既能读短句，又能读长文呢？

科学家为此设计了**循环神经网络（Recurrent Neural Network, RNN）**。
RNN 的核心构想是：**网络结构固定不变，但配一个随时更新的“备忘录小本子（隐藏状态 $h_t$）”！**

```
输入词 x_1 ("我")   ──► [ RNN 核心网络 ] ──► 输出最新备忘录 h_1
                                │ (把备忘录传递给下一步)
                                ▼
输入词 x_2 ("喜欢") ──► [ 同一个 RNN 网络 ] ──► 输出最新备忘录 h_2 (此时包含"我喜欢"的全部语境)
                                │
                                ▼
输入词 x_3 ("大模型") ──► [ 同一个 RNN 网络 ] ──► 输出最新备忘录 h_3
```

每个时间步 $t$，同一个 RNN 网络只接收两样东西：
1. **上一步传过来的备忘录** $h_{t-1}$
2. **当前进来的这 1 个新词** $x_t$

通过矩阵乘法与激活函数更新备忘录：
$$ h_t = \tanh(W_h h_{t-1} + W_x x_t + b) $$
其中：
- $W_x$ 是针对新词的权重矩阵；
- $W_h$ 是针对历史备忘录的权重矩阵；
- $\tanh$ 是激活函数，把所有数字压缩在 $[-1, 1]$ 之间，防止数值无休止放大。

### 4. 为什么强大的 RNN 和 LSTM 最终被历史无情淘汰？
尽管 LSTM 和 GRU 引入了复杂的门控机制，但在大模型时代，RNN 撞上了一堵无法逾越的物理高墙：

1. **信息串行的「传话游戏」缺陷（长程遗忘与梯度消失）**：
   - 文本必须一个词接一个词地顺序传递。如果一句话长达 1000 个词，第 1 个词的信息必须经历 1000 次矩阵乘法才能到达末尾。
   - 在数学上，多次连乘会导致浮点数的**梯度消失（数值缩小到 0）**或**梯度爆炸（数值溢出为 NaN）**。哪怕最先进的 LSTM，在超过 100~200 个词后，对前文的记忆也基本荡然无存。
2. **算力杀手：完全无法在 GPU 上并行训练！**
   - 现代 GPU 内部有上万个计算核心，GPU 最强大的地方在于**同一毫秒同时做数千个矩阵相乘**。
   - 但是 RNN 要求：**必须先算完第 1 个词，拿到 $h_1$ 之后，才能算第 2 个词；算完第 2 个词才能算第 3 个词！**
   - 意味着 99% 的 GPU 核心只能闲置排队等待！训练速度慢如蜗牛，根本无法利用海量互联网数据进行缩放（Scale）。

## ⚡ 五、第四代：Transformer 的横空出世（2017 至今）

2017 年，Google 发表了震动整个 AI 领域的著名论文：
**《Attention Is All You Need》（注意力就是你所需要的一切）**。

Transformer 做出了一个在当时看似离经叛道、甚至疯狂的决定：
> **彻底抛弃所有的循环（RNN）和时间步串行连接！一个都不留！**

### Transformer 为什么能一统天下？
1. **任意两词之间距离永远是 $O(1)$**：
   - 不管一篇文章有 10 个词还是 10 万个词，Transformer 的**自注意力机制（Self-Attention）**让文章中任意一个词与另一个词之间，直接通过矩阵点积相连。
   - 第 1 个词和第 10000 个词可以直接打分产生关联，不再有任何“传话游戏”的信息衰减！
2. **天然契合 GPU 的暴力并行计算**：
   - 一整篇文章输入进来，所有词的 Q、K、V 投影矩阵**在一瞬间同时相乘完成**！
   - GPU 的成千上万个核心全负荷拉满运转，训练吞吐量相比 RNN 提升了几个数量级。
3. **奠定了如今大模型（LLM）的基石**：
   - 正是因为能在海量 GPU 集群上并行计算，才使得人类能够把整个维基百科、GitHub 源码、电子书全部喂给模型，催生了 GPT-3、GPT-4、Llama、Qwen 等如今震撼世界的超级大模型。

## 🎯 总结与下一章预告

回顾人类探寻机器理解语言的 70 年历程：
1. **人工规则**：因语言的无限歧义性与复杂性而崩溃；
2. **统计 N-gram**：因缺乏语义理解与上下文数据稀疏而停滞；
3. **循环神经网络 RNN**：引入连续词向量，但因信息串行传递无法长久记忆，且无法利用现代 GPU 并行算力而遭淘汰；
4. **Transformer**：以完全并行的自注意力机制一统天下，成为当今所有大模型的唯一通用底座。
